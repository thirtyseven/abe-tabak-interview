# Abraham “Abe” Tabak — Family interview

Consolidated family-informed transcript and annotations for the July 1988 interview.

[Read the interview](https://thirtyseven.github.io/abe-tabak-interview/)

The reader embeds the original YouTube video and supports timestamp navigation. Companion Markdown, plain-text, and subtitle files are included.

Family corrections are made in the browser and exported as JSON. A validated
merge script in `pipeline/import_family_corrections.py` incorporates each batch
into the canonical transcript under `transcripts/`; rebuilding the reader then
publishes those corrections for everyone.
